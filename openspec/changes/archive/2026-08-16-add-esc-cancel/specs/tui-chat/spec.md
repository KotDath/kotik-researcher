# Spec delta: tui-chat

## ADDED Requirements

### Requirement: Отмена текущего запроса по Esc

Во время стриминга ответа пользователь SHALL иметь возможность отменить
запрос клавишей Esc. При отмене стрим прекращается, уже полученная часть
ответа MUST остаться в области истории, после неё в истории SHALL
появиться системное сообщение об отмене. Отменённая пара «вопрос-ответ»
MUST НЕ попадать в контекст агента (историю диалога для последующих
запросов). После отмены приложение SHALL позволять продолжить диалог.
Нажатие Esc вне стриминга SHALL игнорироваться и MUST НЕ изменять поле
ввода.

#### Scenario: Отмена в середине стриминга

- **WHEN** идёт стриминг ответа, агент успел прислать часть текста, и
  пользователь нажимает Esc
- **THEN** стрим останавливается, полученная часть ответа остаётся в
  области истории, после неё появляется системное сообщение об отмене,
  поле ввода снова позволяет отправить следующее сообщение

#### Scenario: Отмена до первого чанка

- **WHEN** пользователь нажимает Esc после отправки сообщения, но до
  получения первого чанка ответа
- **THEN** в истории остаётся сообщение пользователя и появляется
  системное сообщение об отмене; записи ассистента не создаётся

#### Scenario: Отменённый запрос не попадает в контекст агента

- **WHEN** пользователь отменил запрос и отправляет следующее сообщение
- **THEN** агент получает историю диалога без отменённой пары
  «вопрос-ответ» (как её частичного ответа, так и промпта)

#### Scenario: Esc вне стриминга

- **WHEN** стриминг не идёт и пользователь нажимает Esc при
  редактировании поля ввода
- **THEN** ничего не происходит: набранный текст в поле ввода не
  изменяется, запрос не отменяется, приложение не завершается

#### Scenario: Сохранение набранного ввода при отмене

- **WHEN** пользователь набрал текст в поле ввода во время стриминга и
  нажимает Esc
- **THEN** стрим отменяется, а набранный текст остаётся в поле ввода и
  может быть отредактирован или отправлен

#### Scenario: Скролл при отмене

- **WHEN** пользователь отмотал историю вверх во время стриминга и
  нажимает Esc
- **THEN** вид прилипает к низу истории, системное сообщение об отмене
  видно на экране

#### Scenario: Повторный Esc после завершения стрима

- **WHEN** стрим уже завершился (успешно или отменой) и пользователь
  нажимает Esc ещё раз
- **THEN** дополнительных сообщений в истории не появляется, состояние
  приложения не меняется
