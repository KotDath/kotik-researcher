- 2026-07-28 · скоуп фичи · проброс thinking + глобальная настройка уровня · пользователь: «Проброс + глобальная настройка», пер-чат не нужен

- 2026-07-28 · гранулярность настройки · свой уровень на каждого провайдера, запоминается · пользователь: «у каждого провайдера свой уровень ризонинга, что ему доступен»
- 2026-07-28 · набор уровней в UI · весь набор SDK (off + getAvailableThinkingLevels(), включая minimal/xhigh) · верификация-вопрос: пользователь подтвердил фильтрацию возможностями модели вместо жёстких 5 уровней из vision
- 2026-07-28 · дефолт уровня для нового провайдера · включённый (low/medium) · видимость фичи «из коробки» важнее экономии токенов
- 2026-07-28 · применение смены уровня · немедленно ко всем активным сессиям, со следующего запроса, стрим не рвём · живость настройки важнее консистентности сессии
- 2026-07-28 · interleaved thinking · каждая порция — отдельный блок в хронологической позиции · хронологическая точность важнее простоты UI
- 2026-07-28 · отвергнуто: агрегация всех порций reasoning ответа в один блок · теряется хронология относительно tool-вызовов
- 2026-07-28 · сворачивание · развёрнут при стриминге, auto-collapse по завершении, из истории всегда свёрнут · компактность истории важнее сохранения UI-состояния
- 2026-07-28 · оборванный reasoning · виден в живой ленте, в историю не пишется; auto-retry заменяет без дублей · чистота истории важнее полноты (LRN-20260728-002)
- 2026-07-28 · модель без thinking · молча, без плейсхолдеров; настройка видна всегда · зафиксировано как норма, снимает блокер «а вдруг событий нет»
- 2026-07-28 · хедер блока · лейбл + длительность («Thinking · 12s»), тикает вживую, хранится · паттерн Claude UI / OpenCode по запросу пользователя
- 2026-07-28 · оформление блока · приглушённый серый (--text-dim), курсив, линия-отступ, иконка-лампочка; тема НЕ меняется · скриншот-референс OpenCode; приложение уже тёмное
- 2026-07-28 · персистентность длительности · sidecar JSON (sessionFile+contentIndex → durationMs) · SDK длительность не хранит; вычисление из timestamp'ов jsonl отвергнуто — хрупко при tool-вызовах и compaction
- 2026-07-28 · отвергнуто: ручная таблица маппинга уровней per-провайдер в коде · getAvailableThinkingLevels() уже отражает возможности модели; ручная таблица устареет с обновлением pi
- 2026-07-28 · спайк 1.1 (SPIKE_HEADLESS=thinking, deepseek/deepseek-v4-pro, setThinkingLevel('low')→кламп в 'high', живой prompt) · события thinking_start/delta/end ПРИХОДЯТ в message_update.assistantMessageEvent: starts=1 ends=1 chars=166 contentIndex=0 durationMs≈1905; в истории assistant.content=[thinking,text], thinking-часть персистируется · допущение design.md подтверждено, молчаливый режим не активен для текущей модели
- 2026-07-28 · спайк 1.2 (deepseek-v4-pro и deepseek-v4-flash) · supportsThinking()=true для обеих; getAvailableThinkingLevels()=["off","high","max"] — «off» ВХОДИТ в список (расходится с допущением design.md «off не входит»), реальные включённые уровни модели только high/max; setThinkingLevel('low') клампится SDK до 'high' · следствие для реализации: UI строит список как off + available с дедупликацией off; дефолт нового провайдера — первый из low/medium, иначе первый НЕ-off из available; для моделей без поддержки — supportsThinking()=false, чат молчит по спеке
