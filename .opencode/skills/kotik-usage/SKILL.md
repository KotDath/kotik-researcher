# Kotik usage

1. Запустить детерминированный экстрактор:

   ```bash
   node .opencode/skills/kotik-usage/scripts/usage-report.mjs $ARGUMENTS
   ```

2. Показать сгенерированный Markdown-отчёт пользователю дословно. Две
   обязательные таблицы с одинаковой разбивкой стоимости:
   `По ролям и моделям` и агрегированная `По моделям`. Колонки: cache miss
   tokens/cost, cache hit tokens/cost, output tokens/cost, total cost.
   Не сокращать и не пересчитывать их вручную.
3. Не сохранять отчёт на диск без явной просьбы пользователя.
4. Нулевой reported cost не называть бесплатным: провайдер мог не передать
   денежную стоимость.
5. Напомнить, что отчёт — снимок до генерации текущего ответа, поэтому
   токены самого ответа в него не входят.
6. Стоимость считать по встроенным публичным API-тарифам моделей. Не
   называть расчёт фактическим списанием или ценой подписки.

Скоуп по умолчанию — последняя корневая сессия текущего проекта и всё
дерево субагентов. Дополнительно:

- `--session <id>` или позиционный `<id>` — конкретное поддерево;
- `--days <N>` — сообщения текущего проекта за последние N дней;
- `--top <N>` — число самых затратных сессий в финальной таблице.
