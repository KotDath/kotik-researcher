# Lessons Learned

Журнал уроков проекта. Урок появляется после инцидента в SDD-цикле и только
с одобрения пользователя. Промоутится в AGENTS.md или промпт агента при
повторяемости: Recurrence-Count ≥ 3 И ≥ 2 разных changes И в окне 30 дней.

**Как читать:** не загружать целиком. На preflight `/kotik-feature` — grep по
теме фичи. На рефлексии при архивации — полный просмотр.

**Миграция:** файл разросся (~50+ активных уроков) → переезжает в
`docs/lessons/` с индексом в README.md.

## Формат записи

```markdown
### LRN-YYYYMMDD-NNN · <тема>
- **Статус:** pending | promoted
- **Recurrence-Count:** 1 (First-Seen: YYYY-MM-DD, Last-Seen: YYYY-MM-DD)
- **Источник:** <change, где случилось>
- **Урок:** <что делать/не делать — короткое prevention-правило>
- **Почему:** <что сломалось или пошло не так>
- **See Also:** LRN-... (опционально)
```

## Уроки

### LRN-20260728-001 · состояние-на-диске
- **Статус:** pending
- **Recurrence-Count:** 1 (First-Seen: 2026-07-28, Last-Seen: 2026-07-28)
- **Источник:** внешнее ревью конфигурации агентов (P1-3)
- **Урок:** любые вердикты и состояния, влияющие на гейты (Review: APPROVE,
  Status, чекбоксы), фиксируются в файлах change — не в диалоге.
- **Почему:** гейт архивации проверял только чекбоксы tasks.md; вердикт
  reviewer'а существовал только в чате и не переживал сессию — change мог
  уйти в архив без реального ревью.
- **See Also:** —

### LRN-20260728-002 · event-цепочки SDK
- **Статус:** pending
- **Recurrence-Count:** 1 (First-Seen: 2026-07-28, Last-Seen: 2026-07-28)
- **Источник:** project-workspaces-pi-chats (review-цикл 1, major)
- **Урок:** при интеграции событийного SDK трассировать полную цепочку
  событий на один логический исход (напр. `agent_end` + `auto_retry_end` на
  один сбой) и дедуплицировать пользовательские следствия событий, а не
  сами события.
- **Почему:** без трассировки порядка событий pi одна ошибка давала две
  карточки в UI: финальный `agent_end` эмитится до `auto_retry_end`,
  обе ветки безусловно показывали ошибку.
- **See Also:** —

### LRN-20260728-003 · инвалидация renderer-стейта
- **Статус:** pending
- **Recurrence-Count:** 1 (First-Seen: 2026-07-28, Last-Seen: 2026-07-28)
- **Источник:** project-workspaces-pi-chats (review-цикл 2, major)
- **Урок:** после каждой мутации коллекции в main — явная инвалидация
  соответствующего списка/стейта в renderer; нельзя полагаться только на
  событийные bump'ы версии.
- **Почему:** удаление idle-чата не эмитило событий, список не
  инвалидировался — удалённый чат оставался «призраком», клик по нему
  разводил activeChat в renderer и main.
- **See Also:** LRN-20260728-002

### LRN-20260728-004 · grep по node_modules
- **Статус:** pending
- **Recurrence-Count:** 1 (First-Seen: 2026-07-28, Last-Seen: 2026-07-28)
- **Источник:** project-workspaces-pi-chats (reviewer цикл 1, tool-ошибка)
- **Урок:** поиск по node_modules/dist (минифицированные файлы со строками
  >64КБ) — через bash `grep`/`rg` с контекстом, не через grep-инструмент.
- **Почему:** grep-инструмент падает с «Ripgrep JSON record exceeded 65536
  bytes» на минифицированных dist-файлах; потеря времени на обход.
